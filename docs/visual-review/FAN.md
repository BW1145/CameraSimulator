# 理发店：主体动画、深度修正与简化操作

原生预渲染基础画质已通过父任务阶段判断。本次默认入口改为 `http://127.0.0.1:8002/` 的理发店样例：保留源背景，加入局部三维桌面风扇。其他三景未批量改造，未合并或发布；闪光层、大光圈边缘和长焦细节仍未完成最终验收。

风扇底座放在源大理石台面的 Three 世界坐标 `[3.8000004,0.8165531,-6.9500003]`。独立 Blender 射线检查中心及半径6/8/10/12 cm各24点均命中平整 `GEO-Dresser_marble.001`，避开碗盘和手镜。模型约10k三角形，在代码中生成；只有背景、256×128源房间 HDR 探针和小型主体清单需要下载。源位置面积灯仅参与主体打光，不重建整屋。主体接触阴影采用简单近似；模型与打光仍需亲自审图。

积分对每个瞬时的完整不透明结果加权，而非叠加半透明叶片。旋转三叶片按完整周期与余段分配权重，权重和为1；30秒仍最多24个时间样本。只在转子投影区域做额外采样。GPU检查对比快/慢快门时，该矩形角落的静止背景亮度保持一致，叶片区域发生明显变化；测试也检查了30秒的采样上限。此处不代表所有光学运动边缘都已完美还原。

本轮还修正了 `4862bfc` 中对 Cycles Z pass 的解释。透视 Z 是**视轴深度**，此前误当径向距离并再乘cos，导致边缘对焦和遮挡偏近。现按取景旋转使用 `captureZ / projected.w` 还原当前视轴深度；拾取先恢复径向距离再求世界点。

[独立像素中心射线数值](depth-axis-groundtruth.json)；实现依据为 [Cycles camera_z_depth](https://github.com/blender/blender/blob/v4.5.0/intern/cycles/kernel/camera/camera.h#L484-L492)。源Z与射线视轴深度误差为0.46–0.70 mm，符合16位0–64m量化。上一阶段 PLATES.md 的近处5.107m记录使用旧转换，应作为历史记录，不能当作当前准确距离依据。

主体相关资产仅112,169 bytes；加中心底图和深度为2,325,914 bytes。本机生产预览启用gzip，浏览器 Resource Timing 冷加载实测全部正文约 **2.61 MB**、含请求头传输约 **2.62 MB**，包含公共代码、面积灯代码、主体探针、清单和中心图对。其余六机位未请求。没有新增动画帧序列；七机位背景图对仍合计15.44 MB，最多缓存三个机位。

检查完成：构建、资产审计、11项计算测试、13项生产浏览器测试。新增覆盖源视轴Z拾取、静态辐射守恒、快慢快门变化、30秒采样上限、主体探针迟到后切景、机位失败重试及返回、竖幅导出。测试数量用于记录覆盖范围，不替代画质验收。

当前界面没有连续XYZ滑杆：一个按钮代表一个实际拍摄机位。拖动只负责取景，焦距和画幅放在“构图”；对焦与曝光辅助分别展开。面积灯、贴图编码等实现细节留在本说明与场景包，不放进日常操作流程。
