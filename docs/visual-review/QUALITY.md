# 理发店质量修复与联合光学验证

本轮第一阶段完成四个已反馈的可见问题：移除无用标题文案；以实体1px边框绘制九宫格；在任何过滤前把log2 WebP逐纹素解码为RGBA16F线性辐射纹理，再生成线性mipmap；改良风扇底座、接触影、曲面叶片与烤漆/黄铜反射。长焦按需高分辨率、静态闪光和其余三场景仍在制作，本提交不把它们列为完成。

## 数值与行为检查

- GPU插值回归使用已知1与16的辐射纹素，按log2编码量化后期望算术均值约8.5。生产载入路径分别验证双线性插值与1024px棋盘缩小；测光误差小于0.06EV，旧算法约4的几何平均不再成立。
- 九宫格回归比较开启/关闭实际浏览器截图，检查三分之一位置确实有像素变化，不只检查checkbox/hidden状态。
- 慢网首次加载时操作白平衡、焦距和拖动无异常；就绪前不访问缺失的pack/entry。
- 风扇命中保存实际对象的局部点。AF-C点底座不会跳转到头部中心，旋转叶片也可跟随对应对象点。
- 时域采样同时考虑屏幕运动：120px半径、1/500s叶尖约6px行程至少4采样，最多仍24；完整周期及余段权重不变。
- 每个时间样本以自己的深度先完成线性景深，再积分颜色；曝光、白平衡和噪点只在积分后处理，不再混用末相位叶片深度。
- GPU双平面景深fixture：清晰前景背景串色0/255；虚化近轮廓外4px红色63/255，f16时0；512px与1024px宽度扩散17/36px，归一相差1px。CoC上限随分辨率缩放，预览和导出不再分别被固定28px截断。
- 本机正常镜头流程实际播放：快门约28.0FPS，慢门24时间采样约27.3FPS；此数值不代表手机性能。
- 本阶段生产构建、12项计算回归及18项生产浏览器回归通过。数量仅说明上述覆盖范围。

## 尚在完成

单层Z无法恢复遮挡后的背景与镜中虚像深度；极大虚化与细线仍是近似。高分辨率按需层和静态闪光层将在下一素材提交中验证，三场景迁移也需逐景实看和实际视差证据。
