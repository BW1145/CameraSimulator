# 理发店预渲染拍摄样例：第一阶段

这轮按限定拍摄区收紧实现。原始 Blender 光照、材质、玻璃和镜面直接参与离线渲染；浏览器加载底图和匹配深度，不再为全屋逐处重建实时材质。**当前可审画质与资源路线，尚未完成风扇、闪光和景深边缘的最终验收。其他三景没有批量改造。**

生产预览：`http://127.0.0.1:8002/?renderer=plates`。同机位画质诊断加 `&view=source`，固定 M、f/8、1/4 s、ISO 100、5000 K，关闭景深和噪点。运行方式仍为 `npm run build` 后 `npm run preview`；此机其他端口被占用，实际预览落在 8002。

七个离线相机为中心、左/右 30 cm、上/下 20 cm、前/后 30 cm。XYZ 滑杆选择这七个档位，一次一个方向，切换方向会把其余两轴归零；没有声称能组合出未渲染的 XYZ 连续机位。拖动、转向、焦距和画幅用于选定照片的取景。转角会受实际捕获余量限制，避免露出黑边，也不靠暗中改变焦距补边。

资源是独立 [manifest](../../public/scenes/barbershop-plates/manifest.json) 加每机位一张辐射图、一张深度图。首次网络记录仅请求 manifest、center.webp、center-depth.png；没有请求其他机位或 glTF。两张图合计 **2,213,745 bytes**；七个机位图与深度合计 **15,439,316 bytes**，加清单和说明约 15.46 MB。公共 JavaScript/CSS 另计（JS 约 173 KB gzip）。只在选定机位时下载，最多保留三个解码后的机位。

底图不是曝光已烤死的 JPEG。源线性 RGB 在 [-16,+6] EV 范围做 log2 编码，WebP 容器无损；每通道量化误差上限 0.0432 EV，本包没有源高光超出范围。曝光、白平衡、测光、噪点共用同一张图，不生成参数组合图片。1280×536 Z pass 用 PNG RG 两通道存 0–64 m 的 16 位距离，量化间隔约 0.98 mm。

生产验证：9 项计算测试、10 项浏览器测试通过；新路径另做失败重试、延迟左机位后立即返回中心、源深度对焦、自动快门联动和 1365×2048 竖幅导出。实际 35 mm 对焦记录为近处台面 5.107 m、门窗处 9.380 m；A 模式 f/1.4 自动 1/60 s、f/22 自动 4 s。截图和数值用于支持这些局部结论，测试数量不代表所有画质已验收。

当前边界：

- 深度只有首表面，缺少遮挡后的图像、玻璃层和镜中虚像深度；不能承诺大光圈所有边缘都正确。当前景深仍使用 24 次采样和 28 px 上限。
- 镜面使用每个源机位真实渲染的静态反射；取景裁切不会重新计算反射，七个真实机位各有自己的反射。
- 高倍长焦裁切会减少有效像素。若需要 100–200 mm 保持相同清晰度，需要补局部近景层，不能把一张宽幅图当作无限分辨率。
- 现有实时练习球仍在，桌面风扇层和正确的长曝光时间积分尚未完成。原版风扇入口保留。
- 静态背景补光需要单独的闪光辐射层；本样例暂禁用补光强度，避免一个显示可调却不改变背景的控件。

相比全屋自由漫游，已省去碰撞/穿行、所有角落的材质展开、实时全屋面积灯重建和全屋动态镜面。后续应先完成这一拍摄区的主体层与镜头验收，再复用导出工具和场景包清单到其他环境。
